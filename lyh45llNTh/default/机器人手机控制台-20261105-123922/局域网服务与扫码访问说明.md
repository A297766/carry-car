# 局域网服务与手机扫码访问 · 使用说明

配套《机器人手机控制台》，实现在电脑上起一个局域网 HTTP 服务，手机扫二维码即可打开控制台并遥控机器人。

**文档版本**：v1.0　**日期**：2026-11-05

---

## 一、为什么要起本地服务

手机浏览器不能直接打开电脑硬盘上的 HTML 文件（`file://` 无法跨设备访问），必须通过 HTTP 服务提供。同时这带来一个**关键好处**：

> 控制台页面通过 `http://` 访问时，浏览器允许它连接 `ws://` 明文 WebSocket（即 rosbridge）。
> 如果把页面放在 `https://` 地址下，浏览器会因混合内容策略**直接拦截** `ws://` 连接，机器人将无法控制。

所以用本方案（http 访问页面 + ws 连机器人）是最省事的组合。

## 二、快速开始（三步）

### 第 1 步：启动服务

**方式 A（推荐）**：双击目录下的 `启动局域网服务.bat`

**方式 B**：命令行执行

```powershell
cd "D:\Documents\qwen-agent\lyh45llNTh\default\机器人手机控制台-20261105-123922"
python start_server.py
```

启动后终端会打印：

```
  ============================================================
   机器人手机控制台 · 局域网访问服务
  ============================================================
  本机访问：http://127.0.0.1:8000/
  手机访问：http://172.22.226.234:8000/
  服务目录：D:\...\机器人手机控制台-20261105-123922

  ┌─ 用手机相机或浏览器扫码 ─────────────┐
    ##############    ##    ##    ####  ##############
    ##          ##  ##    ####  ######  ##          ##
    ...（二维码字符画）
  └──────────────────────────────────────┘
```

同时在目录下生成 `qr.png`（二维码图片）。

### 第 2 步：手机扫码

- 手机需与电脑**连接同一个 Wi-Fi**
- 用系统相机、微信「扫一扫」或浏览器扫码均可
- 若终端字符画扫不出来，用手机浏览器打开 `http://电脑IP:8000/`，索引页上有大尺寸二维码图片
- 也可直接在手机浏览器地址栏输入 `http://电脑IP:8000/机器人手机控制台.html`

### 第 3 步：连接机器人

打开控制台后进入「连接设置」页：

1. 机器人侧启动 rosbridge（默认 9090 端口）：
   ```bash
   ros2 launch rosbridge_server rosbridge_websocket_launch.xml
   ```
2. 需要视频画面时再启动：
   ```bash
   ros2 run web_video_server web_video_server
   ```
3. 页面里填 `ws://机器人IP:9090`，点「连接机器人」，顶栏变绿即切换为真实控制
4. 视频流地址填 `http://机器人IP:8080/stream?topic=/camera/color/image_raw`

## 三、扫码打不开？按顺序排查

这是最容易卡住的一步。**九成问题出在 IP 地址不是手机可达的那个网卡上。**

### 排查 1：确认手机和电脑在同一网段

| 检查项 | 方法 | 期望结果 |
| :--- | :--- | :--- |
| 电脑 IP | 终端打印的「手机访问」地址 | 与手机 IP 前三段一致 |
| 手机 IP | 手机 Wi-Fi 设置 → 当前网络详情 | 例：`192.168.1.x` |
| 网段一致性 | 对比两者 | 电脑 `192.168.1.50`、手机 `192.168.1.77` ✅ |

> ⚠️ **特别注意虚拟网卡**：本机实测探测到 `172.22.226.234`，这类 `172.16-31.x.x` 地址常来自 VMware / WSL / Hyper-V / Docker 的虚拟网卡，**手机无法访问**。
> 若打印出的地址属于此类，请用下面的方法手动指定真实的 Wi-Fi 网卡地址。

### 排查 2：手动查出正确的 Wi-Fi 地址

```powershell
ipconfig | Select-String -Pattern "IPv4|适配器|adapter" -Context 0,0
```

找到标注为 **无线局域网适配器 WLAN / Wi-Fi** 的那一段 IPv4 地址，然后用 `--ip` 指定：

```powershell
python start_server.py --ip 192.168.1.50
```

### 排查 3：Windows 防火墙放行

服务监听 TCP 端口，默认可能被防火墙拦。首次运行时若弹出授权窗口，**必须勾选「专用网络」并允许**。

若没弹窗或已拒绝，用管理员 PowerShell 手动放行（把 8000 换成实际端口）：

```powershell
New-NetFirewallRule -DisplayName "Robot Console 8000" -Direction Inbound `
  -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
```

同时确认当前 Wi-Fi 的网络类别是**专用网络**，不是公用网络：

```powershell
Get-NetConnectionProfile | Select-Object Name, NetworkCategory
```

若显示 `Public`，改为 `Private`：

```powershell
Set-NetConnectionProfile -NetworkCategory Private
```

### 排查 4：路由器开了 AP 隔离

部分路由器（尤其访客网络、公司网络）默认开启 **AP 隔离 / 客户端隔离**，同网段设备之间也不互通。

验证方法——在手机浏览器访问电脑上的任意地址，同时在电脑端看服务是否收到请求日志：

```
    [192.168.1.77] "GET / HTTP/1.1" 200 -
```

- **有日志** → 网络通，问题在页面本身
- **无日志** → 被 AP 隔离拦截。解决办法：改用电脑开手机热点，让手机连电脑的热点（此时电脑 IP 通常是 `192.168.137.1`），或在路由器设置中关闭 AP 隔离

### 排查 5：端口被占用

脚本会自动向后尝试 12 个端口（8000→8011）。若仍失败会报错，此时手动指定：

```powershell
python start_server.py --port 8080
```

## 四、命令参数

| 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| `--port` | 指定监听端口，默认 8000（被占用自动顺延） | `--port 8080` |
| `--ip` | 手动指定对外展示的 IP（自动探测到虚拟网卡时用） | `--ip 192.168.1.50` |
| `--qr-only` | 只生成并打印二维码，不启动服务 | `--qr-only --ip 192.168.1.50` |
| `--selftest` | 运行内部自检后退出，不绑定端口 | `--selftest` |
| `--browser` | 启动后用电脑默认浏览器打开索引页 | `--browser` |

**离线获取二维码图片**（不启动服务，适合先把二维码贴到现场）：

```powershell
python start_server.py --qr-only --ip 192.168.1.50 --port 8000
```

生成 `qr.png`，可直接打印或发到群里。

## 五、索引页功能

访问 `http://电脑IP:8000/` 会看到一个自动生成的索引页，包含：

- **大尺寸二维码**（比终端字符画更好扫）
- **可点击的访问地址**
- **直达控制台的按钮**
- **目录下所有可访问文件的列表**（含大小）
- **机器人侧连接提示**

索引页由服务器每次请求时动态生成，新增或删除文件后刷新即可看到，无需重启。

## 六、安全说明

| 项目 | 说明 |
| :--- | :--- |
| 监听范围 | 服务绑定 `0.0.0.0`，同局域网内**任何设备**都能访问 |
| 无鉴权 | 本服务不带账号密码，**不要**在公共 Wi-Fi（咖啡厅、展会）使用 |
| 目录边界 | 只暴露脚本所在目录，已做目录穿越防护，无法读取该目录之外的文件 |
| 传输加密 | 纯 HTTP 明文传输，仅适用于可信局域网 |
| 急停保障 | 控制安全依赖控制台页面自身的急停、松手即停、失联自动急停机制 |
| 停止方式 | 关闭终端窗口，或在窗口内按 `Ctrl+C` |

**建议**：调试期间用电脑开手机热点组成私有局域网，既避开公司网络的 AP 隔离，也避免暴露到公共网络。

## 七、零依赖说明

`start_server.py` **不需要 pip 安装任何第三方库**，仅用 Python 3.7+ 标准库：

| 能力 | 实现方式 |
| :--- | :--- |
| HTTP 服务 | `http.server` + `socketserver.ThreadingMixIn`（支持并发与 keep-alive） |
| 二维码编码 | 内置 QR 编码器，含 GF(256) 运算、Reed-Solomon 纠错码、8 种掩码罚分择优 |
| 二维码图片 | 手写 PNG 编码（`zlib` + `struct`），不依赖 Pillow |
| 终端字符画 | 纯文本输出，任何终端可显示 |
| IP 探测 | UDP connect 技巧（不实际发包）+ 主机名解析回落 |

离线环境、无网环境均可直接使用。

## 九、常见问题

**Q：终端里的二维码字符画扫不出来？**
字符画依赖等宽字体，某些终端字体下会变形。改用手机浏览器访问索引页扫图片二维码，或直接输入地址。也可以运行 `--qr-only` 生成 `qr.png` 后用图片查看器放大扫。

**Q：手机能打开索引页，但控制台页面里连不上机器人？**
说明 HTTP 服务正常，问题在 rosbridge 连接。检查：① 机器人侧 rosbridge 是否启动；② 地址是否写成 `ws://`（不是 `http://`）；③ 机器人 IP 是否正确；④ 机器人防火墙是否放行 9090。可查看页面「连接设置」底部的联调日志，会显示具体错误。

**Q：视频画面显示不出来？**
视频区会自动降级为 Canvas 模拟画面，并在日志里记录加载失败。检查 `web_video_server` 是否启动、8080 端口是否放行。注意视频流地址用 `http://` 而非 `ws://`。

**Q：想换端口或指定 IP，每次都要打参数太麻烦？**
编辑 `启动局域网服务.bat`，把 `start_server.py` 后面的 `%*` 改成固定参数，例如：
```bat
python "%~dp0start_server.py" --ip 192.168.1.50 --port 8080
```

**Q：服务能长期挂着吗？**
可以，脚本用多线程服务且 `daemon_threads=True`。但它无鉴权、明文传输，仅建议在可信局域网内使用，用完关闭窗口。
